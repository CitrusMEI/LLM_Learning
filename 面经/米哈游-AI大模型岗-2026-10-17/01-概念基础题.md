# 一、概念基础题

> 题量：11 题 ｜ 考察重点：Agent、RAG、幻觉、工具调用等核心概念，以及选型判断（RAG vs 微调、RAG vs Agent）。

1. **讲清楚大模型和 Agent 的关系？**
    - 考点：LLM 是推理内核，Agent 在其上叠加规划、记忆、工具与执行循环；两者在自主性、输入输出边界上的差异。

2. **什么是 AI Agent？Agent 核心组件有哪些？**
    - 考点：感知、规划（Planning）、记忆（Memory）、工具（Tools）、执行/反思；常见架构分层与各组件职责。

3. **ReAct 的思想是什么？CoT 与 ToT 的区别？**
    - 考点：ReAct = Reasoning + Acting 交替推进；CoT 是单链线性推理；ToT 是树状搜索、可回溯与剪枝；三者的成本与适用场景。

4. **什么是幻觉？幻觉产生原因，怎么缓解？**
    - 考点：定义与分类；来源（训练语料、解码随机性、知识边界、上下文误导）；缓解手段（RAG、引用约束、校验复核、低 temperature、微调与评测）。

5. **Function Calling 工具调用原理是什么？**
    - 考点：工具 schema 如何注入模型、模型生成结构化调用参数、宿主执行并回填结果、循环终止条件。

6. **RAG 完整流程是什么？RAG 解决什么问题，有什么短板？**
    - 考点：索引（解析—分块—Embedding—入库）→ 检索 → 重排 → 生成 → 评估；解决私域/时效知识、降低幻觉；短板在检索质量、多跳推理、长文档与上下文噪声。

7. **RAG 和微调如何选型？什么场景用 RAG，什么场景选微调？**
    - 考点：知识注入 vs 行为/风格/格式对齐；从数据量、更新频率、可解释性、成本与延迟几个维度做决策，也可组合使用。

8. **RAG 和 Agent 的区别？两者如何结合？**
    - 考点：RAG 是「检索增强生成」的单步能力，Agent 是多步规划与工具调用的执行体；结合方式包括 Agentic RAG、把检索封装为 Agent 工具、用 Agent 控制检索策略。

9. **Embedding 是什么？向量库作用？**
    - 考点：文本到语义向量的映射与相似度检索；向量库负责索引、ANN 检索、元数据过滤与持久化；与关键词检索（BM25）的互补关系。

10. **上下文窗口超限有哪些处理方案？**
    - 考点：截断、摘要压缩、滑动窗口、分层记忆、RAG 召回替代全量上下文、分段处理、利用长上下文模型。

11. **temperature 参数含义，不同业务场景怎么设置？**
    - 考点：采样温度控制输出随机性；创意/闲聊偏高一档，抽取、工具调用、代码、事实问答偏低或 0；需与 top_p 等参数配合。
