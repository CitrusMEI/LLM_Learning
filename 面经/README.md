## 归档规范

- 每篇面经一个目录，命名为 `公司-岗位-日期`（日期用 `YYYY-MM-DD`）。
- 目录内 `README.md` 为入口，记录来源信息、题量分布、主题主线与复习建议。
- 题目按类别拆分为编号文件：`01-概念基础题.md`、`02-项目深挖题.md`……类别可按岗位实际情况调整。
- `00-阅读版.html` 为单文件阅读版，浏览器打开即可阅读、打印或另存 PDF。
- 题目尽量保留原始表述，只统一中英文间距、标点，并修正明显的 OCR/排版错误；修正项在该篇 README 中注明。
