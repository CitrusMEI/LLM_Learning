一概念基础题11 题

Agent、RAG、幻觉、工具调用等核心概念，以及选型判断。

  1. 讲清楚大模型和 Agent 的关系？

    考点提示

    LLM 是推理内核，Agent 在其上叠加规划、记忆、工具与执行循环；两者在自主性、输入输出边界上的差异。

  2. 什么是 AI Agent？Agent 核心组件有哪些？

    考点提示

    感知、规划（Planning）、记忆（Memory）、工具（Tools）、执行/反思；常见架构分层与各组件职责。

  3. ReAct 的思想是什么？CoT 与 ToT 的区别？

    考点提示

    ReAct = Reasoning + Acting 交替推进；CoT 是单链线性推理；ToT 是树状搜索、可回溯与剪枝；三者的成本与适用场景。

  4. 什么是幻觉？幻觉产生原因，怎么缓解？

    考点提示

    定义与分类；来源（训练语料、解码随机性、知识边界、上下文误导）；缓解手段（RAG、引用约束、校验复核、低 temperature、微调与评测）。

  5. Function Calling 工具调用原理是什么？

    考点提示

    工具 schema 如何注入模型、模型生成结构化调用参数、宿主执行并回填结果、循环终止条件。

  6. RAG 完整流程是什么？RAG 解决什么问题，有什么短板？

    考点提示

    索引（解析—分块—Embedding—入库）→ 检索 → 重排 → 生成 → 评估；解决私域/时效知识、降低幻觉；短板在检索质量、多跳推理、长文档与上下文噪声。

  7. RAG 和微调如何选型？什么场景用 RAG，什么场景选微调？

    考点提示

    知识注入 vs 行为/风格/格式对齐；从数据量、更新频率、可解释性、成本与延迟几个维度做决策，也可组合使用。

  8. RAG 和 Agent 的区别？两者如何结合？

    考点提示

    RAG 是「检索增强生成」的单步能力，Agent 是多步规划与工具调用的执行体；结合方式包括 Agentic RAG、把检索封装为 Agent 工具、用 Agent 控制检索策略。

  9. Embedding 是什么？向量库作用？

    考点提示

    文本到语义向量的映射与相似度检索；向量库负责索引、ANN 检索、元数据过滤与持久化；与关键词检索（BM25）的互补关系。

  10. 上下文窗口超限有哪些处理方案？

    考点提示

    截断、摘要压缩、滑动窗口、分层记忆、RAG 召回替代全量上下文、分段处理、利用长上下文模型。

  11. temperature 参数含义，不同业务场景怎么设置？

    考点提示

    采样温度控制输出随机性；创意/闲聊偏高一档，抽取、工具调用、代码、事实问答偏低或 0；需与 top_p 等参数配合。

二项目深挖题10 题

围绕同一个项目连续追问，验证真实的选型、异常处理与评估闭环。

  1. 讲一遍你的 Agent/RAG 完整项目流程。

    考点提示

    背景与目标、整体架构、关键模块、技术选型理由、个人贡献、上线效果；准备 5–10 分钟版本和 2 分钟版本。

  2. 为什么选择 LangGraph，对比旧版 LangChain 优势？Node、Edge 简单解释。

    考点提示

    图/状态机式编排、显式状态与检查点、循环与条件分支、可控性与可观测性；Node = 执行步骤（模型调用/工具/处理逻辑），Edge = 节点间流转（含条件边）。

  3. Agent 工具调用什么时候会出错？错误调用工具如何处理？

    考点提示

    错选工具、参数幻觉/格式错、工具超时或异常、权限不足、结果不可用；处理手段包括 schema 校验、错误回填让模型纠正、有限重试、fallback、人工兜底。

  4. Agent 出现死循环，反复调用同一个工具，怎么解决？如何熔断？

    考点提示

    步数/时间/Token 预算上限、重复调用与状态哈希检测、反思退出、熔断降级、告警；从 Prompt 与工具设计两侧减少循环诱因。

  5. Agent 的短期记忆、长期记忆分别怎么实现，工程难点是什么？

    考点提示

    短期（上下文窗口、会话缓冲、滚动摘要）、长期（向量库、结构化画像、事实抽取）；难点在写入时机、去重与冲突、检索相关性、隐私隔离与遗忘机制。

  6. RAG 里文本分块大小、重叠度为什么这么设置？分块过大过小会带来什么问题？

    考点提示

    按语义/标题/长度切分，overlap 保证跨块语义连续；块过大召回粗、噪声多、成本高；块过小语义碎片化、指代丢失、召回率下降。

  7. 检索召回效果差，怎么优化？BM25、Rerank 了解吗？

    考点提示

    Query 改写、多路召回、混合检索（BM25 + 向量）、元数据过滤、分块策略、Embedding 微调、Rerank；BM25 基于词频/逆文档频率的精确匹配，Rerank 用交叉编码器对候选精排。

  8. 项目遇到过哪些 BadCase？举一个例子，你是怎么修复的？

    考点提示

    定位链路与归因（数据/检索/Prompt/模型/工具）、修复方案、回归验证与指标变化；要能讲清「怎么发现—怎么定位—怎么修—怎么防再犯」。

  9. 你的项目如何做效果评估？有哪些指标？

    考点提示

    检索侧（Recall@K、MRR、NDCG）、生成侧（正确性、忠实度/幻觉率、相关性）、Agent 侧（任务成功率、步数、工具调用准确率）、线上（满意度、解决率、延迟、成本），以及人工评估与 LLM-as-judge。

  10. 全部依赖大模型 API，如何处理超时、限流？

    考点提示

    分级超时、指数退避 + 抖动重试、限流（令牌桶/并发池）、排队与降级、多供应商/多 Key 容灾、幂等与缓存、监控告警。

三工程 & API 相关题4 题

上线后的稳定性、结构化输出、成本与容错。

  1. 使用大模型 API 会遇到哪些常见问题？

    考点提示

    超时、限流 429、5xx、输出格式不稳定/幻觉、上下文超限、Token 成本高、内容安全、流式中断、模型版本变更导致行为漂移。

  2. 大模型返回不合法 JSON 格式，怎么处理，保证结构化输出？

    考点提示

    JSON mode / Function Calling / 结构化输出约束、schema 校验、解析容错（提取 JSON 片段）、失败重试并回填错误、降级模板兜底。

  3. Token 消耗怎么管控？线上业务如何做成本控制？

    考点提示

    Prompt 压缩与缓存、上下文裁剪、按任务分级路由模型、限制输出长度、批处理、缓存命中、预算与用量监控告警。

  4. 如何做异常捕获、重试策略？

    考点提示

    错误分类（可重试/不可重试）、指数退避 + 抖动、最大重试次数、熔断、超时控制、幂等保证、日志与告警。

四系统设计题6 题

游戏 NPC 场景下的架构、安全、可观测性与取舍。

  1. 设计一个游戏 AI-NPC Agent 系统，支持多玩家同时对话，保证人设稳定、世界观不崩坏，请描述整体架构。

    考点提示

    接入层/会话管理、NPC 人设与世界观知识库、RAG、编排与工具（任务、状态、行为）、记忆分层、安全审核、可观测性；多玩家并发与人设一致性约束。

  2. Agent 上线会有哪些风险？如何防范 prompt 注入、越权调用工具？

    考点提示

    直接/间接 Prompt 注入、越权工具调用、数据泄露、内容违规；防护包括输入输出过滤、工具白名单与参数校验、最小权限、敏感操作人工确认、会话与租户隔离、审计。

  3. 企业级 Agent 系统怎么做日志、监控、审计？

    考点提示

    全链路 Trace（请求→检索→工具→模型→响应）、指标（延迟、Token、成功率、成本）、告警、敏感信息脱敏、审计留痕与合规保存。

  4. LangGraph 有哪些缺点？如果自研 Agent 编排框架，你会怎么设计？

    考点提示

    学习曲线、调试与可观测性、复杂状态管理、生态/版本绑定；自研关注节点与状态抽象、DAG/状态机调度、持久化与恢复、工具插件化、可观测与评测、权限与多租户。

  5. 多个玩家和同一个 NPC 对话，如何做到会话隔离，记忆互不干扰？

    考点提示

    按玩家/会话维度隔离上下文与记忆命名空间、NPC 全局设定与个人记忆分层、并发一致性与读写隔离、数据权限、隐私与清理策略。

  6. Agent 落地目前最大瓶颈是什么？

    考点提示

    可靠性与幻觉、效果评估难、成本与延迟、工具/系统集成、安全与权限、组织数据准备；结合游戏场景谈实时性与内容安全约束。

五HR 面高频题6 题

动机、自我认知与岗位匹配度。

  1. 为什么想来米哈游？为什么选择大模型 Agent 方向？

    考点提示

    对米哈游产品与技术的理解、岗位匹配、个人经历与动机的一致性，避免只谈「公司有名/行业热门」。

  2. 讲讲项目中遇到的最大困难，如何解决？

    考点提示

    STAR 结构、技术深度、个人贡献占比、复盘与沉淀；选「有真实卡点且能讲清解决过程」的例子。

  3. 你的优势和短板分别是什么？

    考点提示

    真实且与岗位相关，优势有例证，短板有改进动作，避免套路化答案。

  4. 玩过米哈游哪些游戏？对于游戏内 AI 有什么想法？

    考点提示

    真实游戏体验、对 NPC/陪伴/内容生成的理解、产品与工程可行性的思考，最好落到具体场景。

  5. 未来 1-2 年职业规划？

    考点提示

    技术深耕路径、与团队目标的契合度、可执行的阶段性目标，避免空泛或与岗位脱节。

  6. 可到岗时间、期望薪资，对实习强度怎么看？

    考点提示

    诚实清晰、边界与承诺；实习时间、地点与强度能给出明确答复。
