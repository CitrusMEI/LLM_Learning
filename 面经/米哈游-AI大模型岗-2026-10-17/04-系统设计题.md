# 四、系统设计题

> 题量：6 题 ｜ 考察重点：结合游戏 NPC 场景做架构设计，同时考察安全、可观测性、框架选型与落地判断。

1. **设计一个游戏 AI-NPC Agent 系统，支持多玩家同时对话，保证人设稳定、世界观不崩坏，请描述整体架构。**
    - 考点：接入层/会话管理、NPC 人设与世界观知识库、RAG、编排与工具（任务、状态、行为）、记忆分层、安全审核、可观测性；多玩家并发与人设一致性约束。

2. **Agent 上线会有哪些风险？如何防范 prompt 注入、越权调用工具？**
    - 考点：直接/间接 Prompt 注入、越权工具调用、数据泄露、内容违规；防护包括输入输出过滤、工具白名单与参数校验、最小权限、敏感操作人工确认、会话与租户隔离、审计。

3. **企业级 Agent 系统怎么做日志、监控、审计？**
    - 考点：全链路 Trace（请求→检索→工具→模型→响应）、指标（延迟、Token、成功率、成本）、告警、敏感信息脱敏、审计留痕与合规保存。

4. **LangGraph 有哪些缺点？如果自研 Agent 编排框架，你会怎么设计？**
    - 考点：学习曲线、调试与可观测性、复杂状态管理、生态/版本绑定；自研关注节点与状态抽象、DAG/状态机调度、持久化与恢复、工具插件化、可观测与评测、权限与多租户。

5. **多个玩家和同一个 NPC 对话，如何做到会话隔离，记忆互不干扰？**
    - 考点：按玩家/会话维度隔离上下文与记忆命名空间、NPC 全局设定与个人记忆分层、并发一致性与读写隔离、数据权限、隐私与清理策略。

6. **Agent 落地目前最大瓶颈是什么？**
    - 考点：可靠性与幻觉、效果评估难、成本与延迟、工具/系统集成、安全与权限、组织数据准备；结合游戏场景谈实时性与内容安全约束。
