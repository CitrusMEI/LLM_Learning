# 二、项目深挖题

> 题量：10 题 ｜ 考察重点：以简历项目为锚点连续追问，验证「是否真的做过」，关注选型理由、异常处理与评估闭环。

1. **讲一遍你的 Agent/RAG 完整项目流程。**
    - 考点：背景与目标、整体架构、关键模块、技术选型理由、个人贡献、上线效果；准备 5–10 分钟版本和 2 分钟版本。

2. **为什么选择 LangGraph，对比旧版 LangChain 优势？Node、Edge 简单解释。**
    - 考点：图/状态机式编排、显式状态与检查点、循环与条件分支、可控性与可观测性；Node = 执行步骤（模型调用/工具/处理逻辑），Edge = 节点间流转（含条件边）。

3. **Agent 工具调用什么时候会出错？错误调用工具如何处理？**
    - 考点：错选工具、参数幻觉/格式错、工具超时或异常、权限不足、结果不可用；处理手段包括 schema 校验、错误回填让模型纠正、有限重试、fallback、人工兜底。

4. **Agent 出现死循环，反复调用同一个工具，怎么解决？如何熔断？**
    - 考点：步数/时间/Token 预算上限、重复调用与状态哈希检测、反思退出、熔断降级、告警；从 Prompt 与工具设计两侧减少循环诱因。

5. **Agent 的短期记忆、长期记忆分别怎么实现，工程难点是什么？**
    - 考点：短期（上下文窗口、会话缓冲、滚动摘要）、长期（向量库、结构化画像、事实抽取）；难点在写入时机、去重与冲突、检索相关性、隐私隔离与遗忘机制。

6. **RAG 里文本分块大小、重叠度为什么这么设置？分块过大过小会带来什么问题？**
    - 考点：按语义/标题/长度切分，overlap 保证跨块语义连续；块过大召回粗、噪声多、成本高；块过小语义碎片化、指代丢失、召回率下降。

7. **检索召回效果差，怎么优化？BM25、Rerank 了解吗？**
    - 考点：Query 改写、多路召回、混合检索（BM25 + 向量）、元数据过滤、分块策略、Embedding 微调、Rerank；BM25 基于词频/逆文档频率的精确匹配，Rerank 用交叉编码器对候选精排。

8. **项目遇到过哪些 BadCase？举一个例子，你是怎么修复的？**
    - 考点：定位链路与归因（数据/检索/Prompt/模型/工具）、修复方案、回归验证与指标变化；要能讲清「怎么发现—怎么定位—怎么修—怎么防再犯」。

9. **你的项目如何做效果评估？有哪些指标？**
    - 考点：检索侧（Recall@K、MRR、NDCG）、生成侧（正确性、忠实度/幻觉率、相关性）、Agent 侧（任务成功率、步数、工具调用准确率）、线上（满意度、解决率、延迟、成本），以及人工评估与 LLM-as-judge。

10. **全部依赖大模型 API，如何处理超时、限流？**
    - 考点：分级超时、指数退避 + 抖动重试、限流（令牌桶/并发池）、排队与降级、多供应商/多 Key 容灾、幂等与缓存、监控告警。
