# 三、工程 & API 相关题

> 题量：4 题 ｜ 考察重点：大模型接入生产环境后的稳定性、结构化输出、成本与容错，偏「上线后才会遇到」的工程细节。

1. **使用大模型 API 会遇到哪些常见问题？**
    - 考点：超时、限流 429、5xx、输出格式不稳定/幻觉、上下文超限、Token 成本高、内容安全、流式中断、模型版本变更导致行为漂移。

2. **大模型返回不合法 JSON 格式，怎么处理，保证结构化输出？**
    - 考点：JSON mode / Function Calling / 结构化输出约束、schema 校验、解析容错（提取 JSON 片段）、失败重试并回填错误、降级模板兜底。

3. **Token 消耗怎么管控？线上业务如何做成本控制？**
    - 考点：Prompt 压缩与缓存、上下文裁剪、按任务分级路由模型、限制输出长度、批处理、缓存命中、预算与用量监控告警。

4. **如何做异常捕获、重试策略？**
    - 考点：错误分类（可重试/不可重试）、指数退避 + 抖动、最大重试次数、熔断、超时控制、幂等保证、日志与告警。
