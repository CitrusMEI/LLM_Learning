# 三、三面

> 题量：4 题 ｜ 形式：项目复盘与工程判断，考察对落地瓶颈、动机和长期迭代的思考。

### 1. 你的 Demo 上线小米，最大缺陷是什么？重构优先改哪里？

**答**：Demo 缺少全链路监控与 Trace，没有分级降级，并发能力弱，缺少完整隐私校验。重构优先补全链路追踪、隐私风控、多级降级、badcase 自动收集闭环。

### 2. 端云 Agent 最大落地瓶颈是什么？

**答**：隐私和体验的平衡。全部数据上云有隐私风险；只用端侧模型算力不足，复杂任务效果差。另外弱网场景任务中断，很难续跑。

### 3. 为什么投递小米 Agent，不投其他公司 AI 岗位？

**答**：小米做端云一体的个人助手，和纯云端 Agent 不一样，同时兼顾设备算力、隐私保护，工程挑战很有价值。我想深耕端侧 + 云端协同的 Agent 落地。

### 4. 任务指标长期无法提升，你会怎么做？

**答**：拆解指标定位瓶颈，区分模型、编排、工具、知识库问题，做对照实验迭代。如果提升困难，可以把部分场景切到 Workflow 兜底，不强行全部用 Agent。
