## 复习建议

1. **先画一张端云分层架构图**：端侧层 → 会话层（Redis）→ 工具管理层 → Agent 编排层 → LLM 层（云端 MiLM，SSE 流式）→ 隐私风控层 → 监控。二面 1 和三面 2 的追问都建立在这张图上，画得出来就能接住「哪些任务放端侧」。
2. **死循环与熔断要能落到实现**：单机内存计数 vs 分布式 Redis 计数的差异（多实例隔离、重启/扩容丢状态）是这场的经典对比题，答案里要给 key 设计（sessionId）、TTL、重复调用参数检测、最大调用次数。
3. **RAG 细节别只背名词**：固定分块的缺点要能说出「语义切断 + Lost-in-the-Middle」，HNSW 要能讲「多层有向图 + 上层导航下层精检 + PQ 量化省内存」，并敢报出自己项目里的具体数字（如 768 维）。
4. **系统设计与复盘题用方法论串**：任务失败排查四步（Trace 埋点 → badcase 归类 → 根因判断 → 灰度修复）、指标拆解、Demo 上线缺陷与重构优先级，都要按「怎么发现—怎么定位—怎么修—怎么防再犯」组织。
5. **HR 面紧扣「硬件 + AI」**：为什么选小米、为什么端云协同、1–3 年规划这三题共用一套动机，提前把「设备端智能体」方向讲清楚；挫折题用死循环调试 + 用实验数据对齐分歧的例子即可。
6. **答案的定位**：原文答案是候选人自述，具体项目细节（LangGraph + RAG Demo、Redis 分布式熔断、上下文压缩）可作为回答框架参考，但并非标准答案，复习时应补自己的项目证据。
