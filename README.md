# LLM 学习仓库

大语言模型（LLM）相关的学习、实验与工程资料汇总。

## 目录结构

```
.
├── notes/       学习笔记 — 概念整理、课程笔记、技术备忘
├── projects/    实践项目 — 各子项目/实验的完整工程代码
├── papers/      论文阅读 — 论文 PDF、翻译、阅读笔记与摘要
├── evals/       评估实验 — benchmark 跑分、prompt 对比、模型评测
├── scripts/     工具脚本 — 数据处理、微调、推理、自动化脚本
├── reports/     总结报告 — 周报、实验报告、技术调研输出
└── 面经/        面试经验 — 各公司/岗位面经分类整理与阅读版
```

## 使用方式

- 在每个目录下按主题或日期创建子目录，保持内容独立可追溯
- 笔记建议用 Markdown，实验/脚本注明运行环境和依赖
